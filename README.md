# Rock Paper Scissors Game

A fun and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer in a five-round match, track your score in real time, and see the final winner at the end.

## ✨ Features

* 🪨 Rock, Paper, and Scissors gameplay
* 🤖 Random computer opponent
* 🎯 Five-round match
* 📊 Real-time score tracking
* 🏆 Final winner announcement
* 🎉 Confetti animation when the player wins
* 📱 Responsive design for desktop and mobile
* ⚡ Interactive and easy-to-use interface

## 🎯 How to Play

1. Choose **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects its move.
3. The result of the round is displayed.
4. The score is updated automatically.
5. Play until all **5 rounds** are completed.
6. The final winner is announced.

## 🏆 Game Rules

|    Player   |   Computer  | Result        |
| :---------: | :---------: | :------------ |
|   🪨 Rock   | ✂️ Scissors | Rock wins     |
|   📄 Paper  |   🪨 Rock   | Paper wins    |
| ✂️ Scissors |   📄 Paper  | Scissors wins |
|   🪨 Rock   |   🪨 Rock   | Draw          |
|   📄 Paper  |   📄 Paper  | Draw          |
| ✂️ Scissors | ✂️ Scissors | Draw          |
